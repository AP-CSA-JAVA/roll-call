Roll Call

Load a roster, load a question bank, and let it pick who answers what. Everything below is saved on this device only.

Add a roster

Upload a photo of a printed roster and it'll try to read the names — check the result before saving, handwriting especially can trip it up. Or just type/paste names, one per line.

Add a question bank

Upload a CSV with columns: question, choiceA, choiceB, choiceC, choiceD, correct (correct = A, B, C, or D). Download a blank template

Call on someone

Pick a roster and a topic, then call. Set a think time and the question shows first, with the name revealed when the timer ends. Students marked NP (Not Present) are skipped. Questions don't repeat until the bank is used up.

Choose questions

Only checked questions are asked. Every question in the topic starts checked. Your choices are remembered for that topic.

Attendance 0 NP

Tap a name to mark that student NP (Not Present). NP students are skipped when calling. Attendance starts fresh each day.

Unchecked: any present student can be picked again, even in the same quiz. Checked: each present student is picked only once, across every quiz today, until you click Reset picked students. The list also starts fresh each new day.

Works with "Pick each student only once." A student who misses a question goes back on the list for another try today, usually with a different question. A right answer, or a second miss, takes them off the list.

With think time on, the question appears first and the timer counts down while students discuss. The student's name is revealed when the timer ends. The maximum is 60 seconds.
